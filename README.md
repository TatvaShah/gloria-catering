# Gloria Catering

A mobile-first demo site for Gloria Catering, an event and corporate caterer in Vaughan and Toronto. Prepared by ClaudAura IT Solutions as a prospect preview.

The business takes orders by Instagram direct message and by email. This site helps a guest compose that note, then copy it into Instagram or send it by email.

Public prices, a street address, a phone number, hours, and lead times were not found, so they are not shown.
